# VELORA — Modular Enterprise SaaS Platform

> **"One platform. Every possibility."**  
> An intelligent, modular workspace built to scale with your business.

VELORA is a premium interactive demonstration of an enterprise-grade modular, multi-tenant SaaS platform. Multiple organizations operate independently within a shared software infrastructure with strict logical isolation, dedicated feature modules, domain AI copilots, visual workflow DAG orchestration, and centralized Super Admin fleet governance.

---

## 🌟 Key Product Environments

1. **Public Marketing Website (`/`)**
   - Branded loading sequence with logo mark reveal
   - Ultra-premium hero with 60 FPS restrained architectural canvas animation
   - Interactive miniature product preview with live tabs (Overview, AI, Automations)
   - Multi-tenant cryptographic isolation visualizer
   - Interactive Module Marketplace modal with live enable/disable
   - Event-driven visual workflow pipeline simulation
   - Domain-trained AI copilot preview
   - Transparent pricing calculator with real-time Monthly/Yearly discount toggle
   - Enterprise consultation inquiry form with simulated lead scoring

2. **Tenant Workspace (`/app`)**
   - Instant workspace switcher between 5 companies (*Acme Technologies, Northstar Consulting, Meridian Group, Apex Digital, Crestview Systems*)
   - Operations dashboard with 7-day throughput chart (Weekly, Monthly, Quarterly)
   - Team Management with full CRUD (Search, Filter, Role assignment, Delete)
   - Roles & Permissions matrix across 8 categories with live save feedback
   - In-app Module Marketplace to provision and teardown features on demand
   - 3-panel AI Workspace with 4 domain assistants, model selection (*GPT-4o, Claude 3.5, Local*), and token quota governance
   - Visual Workflow DAG Builder with node append/delete and real-time execution animation
   - 10 Enterprise Integration Gateways (Stripe, HubSpot, Slack, OpenAI, etc.)
   - Throughput & Telemetry Analytics with date filters (7d, 30d, 90d, custom) and CSV export
   - Subscription & Usage billing with invoice history and tier comparison
   - Detailed workspace audit logs with diagnostic payload inspection
   - Security policies (2FA, SAML SSO, session timeout) and scoped API key vault

3. **Platform Super Admin Console (`/admin`)**
   - Global fleet overview ($24,600 MRR, 128 Tenants, 4,820 Users, 99.98% Uptime)
   - Tenant fleet directory with search, filter, and new tenant self-provisioning
   - Tenant partition inspector with dedicated KMS ARN and schema isolation
   - **Simulated "View as Tenant" Impersonation Mode** with top administrative banner and one-click return
   - Global module governance vs fleet adoption rates
   - Subscription revenue management and promo discount applications
   - 8-microservice edge cluster health monitor with round-trip latency pings
   - Global audit logs and cluster edge routing configuration

## 🚀 Quick Start (Local Development)

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

## ☁️ Netlify Deployment

This repository is pre-configured for one-click deployment on Netlify:

- **Build Command**: `npm run build`
- **Publish Directory**: `dist`
- **SPA Fallback Routing**: Handled via `netlify.toml` and `public/_redirects`
- **Security Headers**: X-Frame-Options, X-Content-Type-Options, Referrer-Policy

### Deploy via Netlify CLI:
```bash
netlify deploy --prod
```
Or connect this repository directly in the Netlify dashboard.

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8 (Ultra-fast HMR, sub-15 kB route chunking)
- **Styling**: Tailwind CSS v4 + Custom Enterprise Design System
- **Icons**: Lucide React
- **Routing**: React Router v7 with lazy loading and code splitting
- **State Management**: Shared React Context with automatic `localStorage` synchronization
- **Design Palette**: Warm White (`#F7F8F6`), Brand Green (`#557C68`), Deep Forest (`#304F40`), Soft Sage (`#E7EEE8`), Muted Gold (`#B89A68`)
